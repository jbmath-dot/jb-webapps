# 우리집 식단 & 장보기 (PWA)

주소: https://jbmath-dot.github.io/jb-webapps/family-meals/

## 기능
- 플랜 A(가성비), B(영양균형), C(초간편) 식단과 7일 아침·휴일 점심·저녁 레시피
- 어린이집 휴원일/방학 등록 → 가정 점심 추가 및 쇼핑 중량 재계산
- 금요일 주문, 토요일 오전 배송, 주간 장보기 체크·단가 입력·남는 재료 계산
- 사용 중인 기기 로컬 저장, JSON 내보내기/가져오기
- 설치 가능한 PWA, 첫 접속 이후 오프라인 기본 식단

## 동기화 구조
앱은 시작 시 `weekly-plans.json`을 HTTP로 읽는다. `version: 1`, `week_start: YYYY-MM-DD`, `catalog` 및 `plans`를 만족하고, 사용자가 보고 있는 주의 토요일 날짜와 week_start가 동일하면 A/B/C 식단을 화면에 반영한다. `catalog`는 식재료 코드별 {name,pack,category}, `plans`는 A/B/C별 {theme,B:[7],L:[7],D:[7]}. 각 레시피는 {title,mins,ingredients:{code:grams},steps:[...],prep?:string}. 불일치·네트워크 끊김·검증 실패 시 번들 안의 기본 예시 식단을 유지한다. 키트/둘째 이유식은 별도로 관리한다.

**중요:** ChatGPT 정기 보고서는 앱의 JSON을 자동 변경하지 않는다. 주간 파일을 GitHub 커밋으로 갱신해야 자동 수신된다. 연결 도입 후 금요일 보고서가 이 경로를 갱신하도록 별도 설정할 수 있다.

## 배포
저장소 Settings → Pages에서 main/(root) 배포가 활성화되어야 하며, 브라우저에서 주소 접속 후 홈 화면에 추가로 설치할 수 있다.

## 컬리 가격·품절 연동
- `kurly-products.json`: 공개 확인된 개별 컬리 상품 ID 및 링크(현재 6종). 실제 가격·재고를 의미하지 않음.
- `kurly-price-feed.json`: 마지막 확인 시각이 있는 가격·품절 스냅샷. 현재는 **API 인증키 미설정으로 비어 있음**.
- `kurly-live.js`: 컬리 상품 링크·업데이트 시각·품절 표시, 가격 확인 후 계산 적용 기능. 2시간이 지난 값은 현재 가격으로 인정하지 않음.
- `.github/workflows/refresh-kurly-prices.yml`: 향후 APIFuse API의 `market-kurly` 범위가 허용된 키를 저장소의 Actions secret `APIFUSE_API_KEY`로 제공한 뒤 약 1시간마다 갱신하는 별도 워크플로(실시간 스트리밍 아님).
- GitHub Pages는 정적 호스팅이므로 비밀 API 키를 브라우저 JS에 삽입하지 마세요. 정확한 수량 재고나 배송지별 구매 가능 상태는 이 API가 제공하지 않습니다. 최종 컬리 결제 화면이 기준입니다.

## 공개 페이지에서 확인된 판매가격(수동 기록)
- `kurly-observed-prices.json`: 상품 코드·상품 URL·조회 기록과 함께 **실제로 출처가 확인된 상품페이지 표시가격만** 수록합니다. 임의 예상 가격은 저장하지 않습니다.
- 연결된 `kurly-live.js`는 확인된 표시가격을 보여주되 **실시간 가격이라고 표현하지 않으며**, 확인되지 않은 품목은 가격 미확인으로 둡니다.
- `이 확인가 입력`을 누르면 해당 시점에 기록된 실제 표시가격을 개인 장보기 계산에 반영할 수 있습니다. 앱 자체의 가격 입력란에도 사용자가 컬리에서 확인한 실제 1팩 가격을 입력할 수 있습니다.
- 가격이 변경될 수 있으므로 금요일 주문 직전에 컬리 상품 페이지/결제 화면을 재확인하세요. 품절 여부·배송지별 재고·최종 쿠폰가는 확인되지 않은 상태입니다.
