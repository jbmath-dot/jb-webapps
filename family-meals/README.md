# 우리집 식단 & 장보기 (PWA)

주소: https://jbmath-dot.github.io/jb-webapps/family-meals/

## 기능
- 플랜 A(가성비), B(영양균형), C(초간편) 식단과 7일 아침·휴일 점심·저녁 레시피
- 어린이집 휴원일/방학 등록 → 가정 점심 추가 및 쇼핑 중량 재계산
- 금요일 주문, 토요일 오전 배송, 주간 장보기 체크·단가 입력·남는 재료 계산
- 사용 중인 기기 로컬 저장, JSON 내보내기/가져오기
- 설치 가능한 PWA, 첫 접속 이후 오프라인 기본 식단

## 동기화 구조
앱은 시작 시 `weekly-plans.json`을 HTTP로 읽는다. `version: 1`, `week_start: YYYY-MM-DD`, `catalog` 및 `plans`를 만족하고, 사용자가 보고 있는 주의 토요일 날짜와 week_start가 동일하면 A/B/C 식단을 화면에 반영한다. `catalog`는 식재료 코드별 {name,pack,category}, `plans`는 A/B/C별 {theme,B:[7],L:[7],D:[7]}. 각 레시피는 {title,mins,ingredients:{code:grams},steps:[...],prep?:string}. 불일치·네트워크 끊김·검증 실패 시 번들 안의 기본 예시 식단을 유지한다. 키트/둘째 이유식은 별도로 관리한다.

**중요:** ChatGPT 정기 보고서는 앱의 JSON을 자동 변경하지 않는다. 주간 파일을 GitHub 커밋으로 갱신해야 자동 수신된다. 연결 도입 후 금요일 보고서가 이 경로를 갱신하도록 별도 설정할 수 있다.

## 배포
저장소 Settings → Pages에서 main/(root) 배포가 활성화되어야 하며, 브라우저에서 주소 접속 후 홈 화면에 추가로 설치할 수 있다.

## 마켓컬리 검색 첫 상품 + 컬리 멤버스 가격 (2026-10-26 운영원칙)
- 상품은 컬리에 로그인하여 해당 식재료명으로 검색했을 때 **기본 검색순서 화면에 첫 번째로 노출되는 상품**을 선택합니다. 이전 대표상품/공개 웹 검색의 상위 노출 순위를 1위로 추정하지 않습니다.
- 가격은 그 상품의 **멤버스 계정에 표시된 상품별 실제 적용 단가**만 입력·계산합니다. 일반 판매가, 공개 페이지에 수집된 단가, 예전 자동 API 값은 **멤버스가로 취급하지 않습니다**.
- GitHub Pages 정적 사이트는 이용자 컬리 로그인 정보를 가지고 있지 않아 검색 1위 및 멤버스 가격을 자동 인증·조회할 수 없습니다. 앱 장보기 화면에서 '컬리에서 검색 맨 위 상품 확인' 링크를 누르고 로그인한 화면에서 상품 URL과 멤버스가를 확인한 뒤 '확인' 체크 후 저장하면 기기 내부(localStorage)에 등록됩니다.
- 기록은 마지막 확인 후 **7일 동안만 유효한 표시 가격**으로 계산하고 이후 다시 확인해야 합니다. 컬리의 실제 검색 순서는 로그인·시각·배송지·개별 프로모션에 따라 달라질 수 있습니다.
- 확인하지 않은 항목의 가격은 비워두고, 총액은 미확인 항목을 제외한 **부분합**으로 안내합니다. 쿠폰·적립금·배송비 등의 주문 총할인은 상품별 단가와 분리해 실제 결제 화면에서 최종 확인하세요.
- 기존 가격은 백업 키 'family-meal-old-prices'에만 보관하고, 현재 장보기 계산에는 검증된 멤버스가만 반영합니다. 사이트는 컬리의 로그인 자격증명을 수집하지 않습니다.
- 이전 `kurly-live.js`·`kurly-price-feed.json`·`kurly-observed-prices.json`은 기록으로 남아 있지만 앱에서 로드하지 않습니다. 로그인 인증 없는 APIFuse 자동 조회는 **멤버스 적용가격을 보장하지 않으므로** 예약 갱신을 비활성화했습니다.

## 오늘/주간 레시피 상세 보기 (2026-10-26 보강)
- '오늘'과 '주간'의 메뉴를 눌렀을 때 `recipe-details.js`가 준비 재료표 뒤에 상세 조리 내용을 표시합니다.
- 실제 공개된 유사 원본 레시피의 **참고 링크**와, 가족용으로 변경한 3~5단계 이상 조리법을 분리합니다. 출처가 직접 확인되지 않은 간편 조합은 원본 확인 불가로 표시합니다.
- 진간장·국간장·마늘·올리고당·식용유 등의 **큰술/작은술 계량**, 불 조절, 양념 전 유아식 분리 시점, 첫째의 1끼 식사 예시(밥/고기/채소/국물)를 제공합니다.
- 현재 양념류는 식단의 `catalog` 및 장보기 합산에 자동 추가되지 않을 수 있으므로 조리 전 집의 보유 여부를 확인해야 합니다.
- 이 상세 레시피는 가족 2성인+첫째 기준으로 개발한 **응용 조리안**입니다. 링크의 원본 양념량을 그대로 복제하거나, 모든 조리법이 원본과 일치한다고 보장하지 않습니다.


## 전체 양념 과정 순서형 조리법 (2026-10-26)
- \`recipe-details.js\`가 현재 3개 플랜의 아침·점심·저녁 **총 63개** 메뉴마다 조리 과정을 단계별로 보강함.
- *식재료 계량/손질 → 계량 양념장을 별도 그릇에서 섞기 → 기본 재료 완전히 익히기 → 아이 몫을 양념 전에 덜기 → 어른용 양념장 넣고 중불/중약불에서 조리 → 맛 확인·배식* 전체 순서 수록.
- 맑은 국과 구이가 같이 있는 메뉴는 **국물 간장 양념과 구이 양념을 각각 구분**. 아침 메뉴는 추가 간을 하지 않는 방식으로 준비.
- 계량 단위는 **큰술 15mL, 작은술 5mL**; 2명 성인 몫의 간장양념 기준이며 첫째 제공량은 개별 아이 식욕에 따라 조절할 예시.
- 양념의 진간장·국간장·마늘·올리고당·참기름 등은 아직 장보기 수량 자동합산에 전부 포함된 것은 아니므로 식단 상단 재료표와 별도로 재료 보유 여부를 확인.
- 제시 조리법은 실생활에서 쓰는 가정식 조리 방식을 기반으로 구성한 조정안이며, **모든 메뉴와 정확히 일치하는 외부 원본 레시피를 검증했다는 뜻은 아님**. 출처 링크가 없는 메뉴는 앱에 해당 사실을 표시.


## 장보기 전체 25품목 참고가 기본 입력 (2026-10-26)
- 모든 주간 식단의 장보기 25개 품목에 1팩당 **참고 예상가격** 기본값을 입력합니다. 원본 데이터: `kurly-reference-prices.json`, 실제 앱 입력 코드: `kurly-members.js`.
- 기준: 첫 구매 전용 특가가 아닌 일상적인 컬리 구매가 수준을 가정. 공개 컬리 가격·시세를 참고해 반올림·추정한 값으로, **로그인한 계정의 컬리멤버스 실판매가 또는 컬리 검색 첫 상품 가격으로 검증된 것이 아닙니다.**
- 앱 장보기 합계는 '참고 예상 합계'로 표시합니다. 사용자가 컬리 로그인 화면에서 검색 결과 첫 상품과 멤버스 가격을 직접 확인·저장한 경우 **7일 동안 해당 실확인 값이 우선**합니다.
- 신규 또는 이름이 바뀐 품목은 가격을 임의로 채우지 않고 새 참고가를 검토합니다. 재고·쿠폰·배송비는 별도입니다.

## 메뉴별 시판 완성형 소스 선택 (2026-10-26)
- `ready-sauces.js`: 오늘/주간의 고기·두부 메뉴 상세보기에서 수제 양념을 유지하거나 시판 완성형 소스를 선택할 수 있다.
- 사용 가능한 컬리 상품 페이지: 백설 소불고기양념 500g, 청정원 데리야끼 소스 250g, 다담 안동찜닭 양념 220g(옵션), 다담 매콤두부조림 양념 140g(옵션), 백설 돈까스 소스 255g. 컬리 검색 첫 상품이나 멤버스 가격이라는 인증은 없다.
- 선택 시 어른 2명 기준 소스 g 수치(메뉴당 조정 가능), 계량→아이 몫 사전 분리→성인 양념 적용→완성 순서를 별도 표시하며, 겹치는 직접 만든 주요리 양념 과정만 숨긴다. 국은 별도로 간한다.
- 선택한 소스는 주간 같은 품목끼리 g 합산 후 구매할 병 수를 올림 계산해 장보기 화면에 추가하고, 품목별 구매 확인·집에 남은 g·가격 수정 및 참고 예상합계 계산을 제공한다.
- 초기값은 사용자가 직접 선택하지 않는 한 **수제 양념 유지**, 첫째에게는 양념 전 덜어낸 저염 음식, 둘째 이유식에는 소스를 주지 않는다.
- 시판 소스 기본 가격은 공개 페이지 확인가 또는 옵션별 참고가이며 멤버스 가격을 인증하지 않은 추정/참고 값이다. 개봉 후 보관 및 알레르겐·나트륨 함량은 실제 제품 라벨을 확인한다.
